# Style Hub · 风格衣橱

**女生時尚工作台 / Girls Fashion Workbench**

> 不买新衣，也能穿出下一季的流行。

Style Hub 是專為女生打造的 **AI 時尚工作台**——把你已有的單品、彩妝與飾品收進一個「數字百寶箱」，再結合天氣、場合與最新趨勢，生成每日穿搭方案、折扣情報與省錢成就。

---

## 核心功能

| 模組 | 說明 |
|------|------|
| **數字時尚百寶箱** | 收納衣物、鞋包、飾品、彩妝與護膚品；自動分類、保質期倒數、穿搭次數與 CPW 統計 |
| **今日風格卡** | 根據天氣與場合（上班 / 約會 / Cafe…），從百寶箱抽出「彩妝 + 穿搭 + 髮型」三合一套卡 |
| **潮流雷达 · AI Match** | AI 讀取你的已有單品，直接配出緊跟潮流的完整 Look（Clean Girl / 日韓系 / 歐美復古 / Y2K / 職場輕熟…） |
| **Deal Hunter** | 每日美妝穿搭折扣情報與隱藏優惠碼 |
| **智慧省錢帳本** | 記錄「忍手省下」與「轉賣回血」，搭配 Cost-Per-Wear 分析與成就徽章 |
